## Features

Roblox MultiHub is designed to bring your Roblox setup together:

| | |
| :--- | :--- |
| **Account management** | Keep accounts organized with groups, aliases, notes, search, and list or card views. |
| **Session launching** | Launch games, join specific or private servers, and coordinate multiple accounts. |
| **Window layouts** | Arrange sessions in grids or custom layouts, with support for multiple monitors. |
| **Performance controls** | Adjust FPS limits, graphics settings, process priority, and memory-cleaning options. |
| **Saved presets** | Restore your accounts, games, layouts, and settings from a saved setup. |
| **Everyday tools** | Anti-AFK, macro recording, themes, and startup options. |

*Feature availability and system requirements will be confirmed with the first release.*
